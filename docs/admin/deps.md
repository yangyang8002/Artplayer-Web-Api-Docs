# 依赖与更新

「依赖与更新」页集中管理程序版本、npm 依赖与插件更新。

## 程序版本

- **检查更新**：对比 GitHub Release、npm registry 与远程 `update.xml` 清单，取最高版本
- 显示：当前版本 / 最新版本 / 部署方式（git-source / npm-global / docker / source）
- 有更新时展示更新说明，点击「更新到最新版」执行完整更新流程（自动备份 → 更新 → 重启）

## npm 依赖

- 依赖列表：名称 / 当前版本 / 最新版本 / 状态
- **逐个更新**：对需要更新的依赖单独执行 `npm install <pkg>@latest`（后台进程）
- **更新全部**：一键更新所有依赖

::: tip
依赖更新在后台执行，完成后**重启服务**生效。检查结果缓存 30 分钟。
:::

## 插件更新

列出已安装插件的版本 / 来源 / 状态：

- npm / URL 来源插件：一键按原来源更新（保留配置与启用状态）
- 文件型插件：提示手动上传新版

详细插件功能见 [插件管理](/admin/plugins)。
