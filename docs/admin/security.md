# 安全中心

## IP 统计

- 按窗口（5 分钟 / 1 小时 / 24 小时 / 全部）查看 IP 请求数与流量
- 支持搜索、按请求量 / 流量排序、分页

## 异常检测

自动标记异常 IP 并给出原因（如每分钟请求数、流量超阈值等），可一键封禁：

- 每窗口请求数阈值（reqPerMin）
- 每窗口流量阈值（MB）
- 每窗口登录失败次数阈值

## 封禁与白名单

- **封禁**：禁止该 IP 全部访问（重启后持久化）
- **白名单**：绕过 PoW / 限流 / 弹幕限频，且不参与异常判定
- 支持手动添加 / 移除

## 登录记录与防护

- 记录每次登录尝试（成功 / 失败 / 锁定），显示 IP、账号、地区与原因
- **失败锁定**：配置最大失败次数、统计窗口与锁定分钟数；触发锁定后拒绝该 IP 登录
- 可从记录中一键封禁 / 加白

## 地理信息

- 内置 ip2region v4 / v6 数据库（xdb），可一键更新
- **全球 / 中国地图**：ECharts 热力地图展示各 IP 分布（需 CDN 可达）

## PoW 与限流

PoW 防火墙、全局速率限制与弹幕频率限制的配置位于「服务器配置」，与安全中心联动防护。
