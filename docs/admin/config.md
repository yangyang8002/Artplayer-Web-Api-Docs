# 服务器配置

配置面板分为多个区域，保存后部分需要重启生效。

## PoW 工作量证明

- **启用**：客户端发送弹幕等写请求前需完成工作量证明校验
- **难度**：1-6，越高客户端计算越慢、防刷越强

## 速率限制

- **窗口（秒）** 与 **上限**：全局每 IP 请求频率限制（如 60 次 / 60 秒）

## 弹幕频率限制

- 每 IP 每分钟可发送弹幕条数上限（默认 10）

## 弹幕渲染

- **每秒上限**：播放器每秒最多渲染的弹幕条数（默认 250）
- **速度抖动 %**：每条滚动弹幕随机 ±% 速度（默认 5）

## CDN

- 启用后播放器页面资源（前端脚本等）从 CDN 域名加载

## 主题

- **播放器主题**：选择播放器默认主题（10 套）
- **后台主题**：后台自身配色，切换即时生效（保存在本地）

## 账号

- 修改密码（原密码 + 新密码）
- 更换用户名（需当前密码验证）

## 管理入口

- `security.adminPath`：自定义后台入口路径（如 `secret` → `/secret/`）
- `trustProxy`：反向代理部署时信任 X-Forwarded-For（获得真实客户端 IP）

## 安全与会话

- 会话有效期（分钟）：登录 token 过期时间
