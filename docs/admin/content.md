# 弹幕 / 视频 / 字幕

## 弹幕列表

- 支持按**视频码**、**弹幕内容**筛选
- 分页浏览（每页 50 条），显示时间 / 视频 ID / 内容 / 颜色 / 类型（滚动 / 顶部 / 底部）
- 右侧「视频码」面板按弹幕量排序，点击快速筛选

## 视频管理

- **添加 / 更新映射**：填写视频码与链接保存；可选关联字幕（Ctrl 多选）
- **批量操作**：全选 → 删除所选
- **快捷代码**：一键生成 HTML / Markdown / JS / 直链 四种格式的播放器嵌入代码
- 同一视频 URL 的映射自动记录（播放器加载时）

## 字幕管理

### 添加字幕

- **链接**：填写字幕 URL（支持自动识别语言），可选「立即下载到本地」（本地化）
- **文本内容**：粘贴 WEBVTT / SRT 内容
- **上传文件**：支持 .srt / .vtt / .ass / .ssa / .webvtt，多选上传

### 字幕操作

- **应用 / 取消**：将字幕应用到全部视频映射（取消则仅保留关联关系）
- **本地化**：把远程链接字幕下载到服务器本地存储（限 5MB，防内网地址）
- **搜索**：按名称 / ID / 语言过滤

### 播放器侧

- 播放器自动检测视频同目录字幕（多语言自动匹配，如 `video.zh.vtt`）
- 后台字幕库中的字幕在播放器「字幕选择」中可直接加载
