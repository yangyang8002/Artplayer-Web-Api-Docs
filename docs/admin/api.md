# API 管理

## 独立开关

每个 API 路径可独立控制：

| 默认规则 | 说明 |
| --- | --- |
| `/api/config/public` | 播放器公共配置 |
| `/api/danmu/` | 弹幕读写（v1 兼容） |
| `/api/danmu/v3/` | 弹幕读写（DPlayer 兼容） |
| `/api/video/map` | 视频映射记录 |
| `/api/video/resolve` | 视频地址解析 |
| `/api/subtitle/detect` | 字幕检测 |
| `/api/pow/verify` | PoW 校验 |

每条规则可设置：

- **启用 / 停用**：停用后返回 403
- **RPS 上限**：每秒请求数（滑动窗口，内存计数）
- **带宽上限**：每秒响应字节数

## 统计

- 三层时间桶：1 秒（保留 1 天）、60 秒（保留 30 天）、1 小时（保留 90 天，受 retentionDays 限制）
- 统计持久化到磁盘（60s 定时 + 退出时），重启不丢
- **实时曲线**：按跨度选择桶精度（≤1 天用秒桶、≤30 天用分钟桶、其余用小时桶），堆叠柱状图展示各 API 请求分布
- 显示：总请求数、总流量、每个路径的请求数与流量、运行时长

## 保留策略

`retentionDays`（1-90 天）控制小时桶保留长度；配置保存后立即生效。
