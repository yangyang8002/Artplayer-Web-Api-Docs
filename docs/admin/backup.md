# 备份中心

## 手动备份

- 选择**备份内容**：数据库数据 / 服务器配置
- 选择**备份目标**：本地 / 云端 / 本地 + 云端
- 云端目标需先在「管理配置 → 云端同步」中保存连接配置

## 定时备份

- 启用自动备份，设置**间隔（小时）**与**保留份数**
- 保存配置即重置计时：首次启用时立即备份一次

## 云端同步

支持以下目标类型：

| 类型 | 说明 |
| --- | --- |
| FTP / FTPS | 标准 FTP 协议（可选加密） |
| SFTP (SSH) | SSH 文件传输 |
| WebDAV | 通用 WebDAV 存储 |
| OpenList (AList 兼容) | OpenList / AList 实例 |

每个配置可独立启用 / 停用、测试连接、编辑、删除。本地备份完成后自动同步到所有启用的云端配置（失败仅记录，不影响备份本身）。

## 备份列表

- 本地备份：下载 / 恢复 / 删除，支持多选批量恢复
- 云端备份列表：下载到本地 / 删除
- **批量恢复**：按时间从旧到新依次恢复所选备份（数据 / 配置协调同步，全程暂停写入）

::: warning
恢复会**覆盖当前数据**。恢复配置时保留当前数据库连接与备份配置，避免恢复后连错库。
:::
