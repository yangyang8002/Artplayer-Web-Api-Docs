# 播放器使用

播放器页面为单页应用，通过 URL 参数控制：

```
http://localhost:1919/player/?url=https://example.com/video.mp4
```

## URL 参数

| 参数 | 说明 |
| --- | --- |
| `url` | 视频地址（mp4 / m3u8 / flv 直链） |
| `vid` | 指定视频码（不填则按视频地址自动生成/记录） |
| `theme` | 播放器主题（如 `theme=bilibili`，默认取服务器配置） |
| `lang` | 播放器语言（zh / zhHant / wyw / en / ja / fr） |

## 弹幕功能

- **发送弹幕**：输入内容后回车，支持滚动 / 顶部 / 底部三种类型，可自定义颜色
- **弹幕设置**：透明度、数量（密度）、速度、底边距、顶/底堆叠开关
- **视频码**：同一视频码的所有观众共享弹幕；服务端自动分配 8 位视频码
- **屏蔽**：管理员在后台维护屏蔽词，命中屏蔽词的弹幕会被拒绝
- **DPlayer 兼容**：`/api/danmu/v3/?id={vid}` 可直接对接 DPlayer 弹幕生态

## 字幕

- 播放器自动检测视频同目录的字幕文件（.srt / .vtt / .ass / .ssa），支持简 / 繁 / 日 / 英等多语言
- 后台可维护字幕库、将远程字幕**本地化**下载到服务器
- 播放器支持字幕大小 / 底距调节与多字幕切换

## OpenList / AList 视频

在备份中心配置 OpenList（AList 兼容）云端实例后，直接粘贴实例链接播放即可：

- 播放器自动调用服务端 `/api/video/resolve-link`，由实例 API 解析出**云盘直链**（二次地址）进行播放
- **视频码（vid）与字幕检测仍以原始 OpenList 链接为准**：直链带签名 / 会过期，也不影响弹幕与同目录字幕的关联
- 解析失败时回退为原始链接播放；未配置实例的链接不受影响

## 视频码（vid）

播放器加载视频后自动调用 `/api/video/map` 记录 `vid → url` 映射。同一 URL 会复用已有 vid；后台「视频管理」可查看与导出全部映射。

## 快捷代码

后台「视频管理」可为每个视频一键生成播放器嵌入代码：

- **HTML**：`<a href="/player/?url=..." target="_blank">播放</a>`
- **Markdown** / **JS** / **直链** 格式同样支持

## 截图与统计

- 播放器内置**截图**功能（保存 PNG 到下载目录，跨域视频可能受限）
- 快捷键与画中画（PIP）、网页全屏、原生全屏均可用
