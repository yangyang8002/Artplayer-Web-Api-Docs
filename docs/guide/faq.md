# 常见问题 (FAQ)

## 如何修改默认账号密码？

登录后台后进入「服务器配置」→ 底部账号区域，可修改用户名 / 密码。首次启动向导也会引导设置新密码。

## 管理入口地址忘了 / 被改动了？

管理入口由配置 `security.adminPath` 控制。若忘记入口：

```bash
# 修改 data/config.json 中的 "adminPath" 字段
# 默认入口为 /admin/
```

## 视频码（vid）是什么？会冲突吗？

视频码是视频的弹幕标识。播放器首次播放某 URL 时自动分配 8 位随机码并记录映射；同一 URL 复用同一 vid。后台「视频管理」可手动添加 / 删除映射。若担心冲突，可手动指定 vid（4-32 位字母数字）。

## 弹幕发送失败 / 被拒绝？

- 弹幕包含**屏蔽词** → 后台「屏蔽词管理」维护
- 触发**弹幕频率限制**（默认每分钟上限）→ 后台「服务器配置」调整
- 触发**全局速率限制** → 后台「服务器配置」调整

## 如何关闭 PoW 防火墙？

「服务器配置」→ PoW 工作量证明 → 取消「启用」。关闭后所有请求直连（无工作量证明校验），安全性下降。

## 数据存在哪里？可以换数据库吗？

默认存于 `data/` 下的 JSON 文件。进入「数据库管理」可切换 SQLite / MySQL / MariaDB / PostgreSQL / MongoDB，切换时**自动迁移全部数据**，无需重启。

## 如何备份？

「备份中心」支持手动 / 定时备份（数据 + 配置），目标可为本地或云端（FTP / FTPS / SFTP / WebDAV / OpenList 兼容）。恢复时按时间从旧到新批量恢复。

## 更新后服务起不来？

- 查看 `data/update.log` 与 `out.log`
- 更新前已自动备份 `data/`；代码问题可 `git checkout -- .` 回退代码（数据不受影响）
- 常见原因：npm 源不可达导致依赖安装失败 → 设置镜像源后重试

## 插件可以执行任意代码吗？

可以。插件运行在服务进程内，**仅安装可信来源**的插件。官方插件市场条目均来自本仓库 `plugin-registry.json`。

## 播放器跨域无法播放视频？

播放器是后端代理无关的前端直连。若视频资源不允许跨域（无 CORS 头），截图等功能会受限；可配置 nginx 反代（见 `nginx.conf.example`）实现同源访问。

## 支持的视频格式？

mp4（原生）、m3u8（hls.js）、flv（flv.js）。浏览器不支持的解码会显示错误提示并建议换用支持的格式。
